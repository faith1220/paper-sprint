# 研究 brief 工作表

此工作表供人／agent 定题讨论。CLI 的执行配置在项目 `brief.json`；讨论决定须同步到 JSON。未确定处写“待确认”，不把猜测写成已知事实。

| 项目 | 填写内容 |
| --- | --- |
| 任务与领域 | 输入、输出、典型使用条件 |
| 核心问题 | 现有方法在哪类样本或条件下失效 |
| 有边界的目标 | 哪个指标／成本／适用条件需要改善 |
| 强基线 | 方法、版本、选择理由、复现材料 |
| 预期贡献 | 组合、轻量适配或新场景验证；区分来源技术 |
| 目标期刊 | 名称；如未确定可先列范围 |
| 分区依据 | JCR／中科院／其他，年份、类别、核查来源；不可互换 |
| 数据 | 数据集、版本、许可证、使用条件 |
| 划分原则 | 训练／开发／测试清单；按样本、被试、设备或场景隔离的依据 |
| 评价 | 主指标、方向、单位，最小有意义差异 |
| 硬件 | 实际可用设备；A100 40GB 仅是可替换示例 |
| 预算 | 总 GPU 小时、总运行数、开发和故障预留 |
| 可接受的最小成果 | 支持什么范围的论断即可进入写作 |
| 停止条件 | 不能复现、无改善、成本超限或必要假设失效 |
