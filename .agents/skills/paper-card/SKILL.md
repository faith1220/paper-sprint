# 读出可以复用的机制

先读项目 brief，确认任务、数据条件和基线。用 [机制卡模板](../../../templates/paper-card.md) 记录 2～3 篇核心论文；其他近邻可以只保留检索记录，避免无限扩展阅读范围。

1. 核对论文标题、作者、年份、DOI／稳定链接及可合法获得的全文。标清实际读过的材料；只有摘要时不推断实现细节。
2. 对每项拟采用机制记录原文页码／节／图／公式、输入输出、计算顺序、参数／训练目标、成立假设和作者报告的适用条件。把原文事实、自己的推断、尚未核实的部分分开。
3. 将论文数据流映射到当前基线，指出插入点、张量维度、额外监督、训练成本和推理成本。原文指标只作为文献结果，不登记为本项目运行。
4. 分别核对论文、代码、权重、数据的许可与使用条件。开源网页可见不等于允许任意复用；无许可证时保留 unknown，优先独立实现思想或换用可授权材料，不复制来源代码。
5. 对组合名称、机制别名、任务和“机制 A + 机制 B”检索近邻；记录日期、检索式、来源、最相近工作及实际差别。未检出不等于证明首次提出。

本仓库没有论文搜索 API。使用当前可用检索工具或用户提供的文献；工具不可用时输出待检索清单，不伪装完成。结束时交付机制卡、近邻检查结果、复用条件和最多三个值得进入组合讨论的机制。
